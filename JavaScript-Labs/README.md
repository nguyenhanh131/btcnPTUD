## Mục tiêu
 
Thực hiện 3 bài Lab để vận dụng JavaScript xây dựng các chức năng tương tác cho website: nắm nền tảng ngôn ngữ, thao tác DOM và sự kiện, rồi rút gọn công việc bằng jQuery.
 
---
 
## Nội dung từng Lab
 
### Lab 08 · JavaScript 1: Language Foundations
Bật/tắt JavaScript, thẻ `<script>` và `<noscript>`, built-in objects (String, Date, Math), mảng, hàm (hàm ẩn danh, truyền hàm làm tham số), phạm vi biến, đối tượng và mảng đối tượng.
 
### Lab 09 · JavaScript 2: DOM and Events
Chọn và thay đổi phần tử DOM, duyệt cây DOM, tạo/xóa phần tử, xử lý sự kiện (click, mouseover, load, focus, blur, submit), kiểm tra dữ liệu form, gỡ lỗi bằng DevTools.
 
### Lab 10 · JavaScript 3: jQuery
jQuery selectors, sự kiện, thao tác DOM, hiệu ứng/animation và GET request với jqXHR.
