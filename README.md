### Bài 1 · Luyện selector qua trò chơi
Chơi hoàn thành **CSS Diner** và **CSS Speedrun**, ảnh chụp kết quả được đặt ở trang chủ.

### Bài 2 · Định dạng văn bản
Làm quen với màu chữ, căn lề, đường viền, đổ bóng chữ (`text-shadow`), ảnh nền lặp và cắt chữ tràn bằng `overflow`.
`BaiTap2.html`

### Bài 4 · Thanh menu ngang
Dàn các mục menu trên một hàng bằng `display: inline-block`.
`BaiTap4.html`

### Bài 5 · Trang giới thiệu Best Shared Hosting
Dựng một landing page hoàn chỉnh từ bố cục đến màu sắc.
`BaiTap5.html`

### Bài 6 · Portfolio cá nhân
Có phần tab chuyển nội dung và bộ sưu tập ảnh xếp bằng CSS Grid.
`BaiTap6.html`

### Bài 7 · Bố cục trang web
Chia trang thành `header`, `nav`, `main`, `footer` bằng CSS Grid.
`BaiTap7.html`

### Bài 8 · Hero Section
- **8a:** Heroes of JavaScript and HTML, dùng `position` và `z-index` để chồng lớp.
`BaiTap8a.html`
- **8b:** The Bat Family, thêm hiệu ứng `:hover` kết hợp `position`.
`BaiTap8b.html`

### Bài 9 · Font Awesome
Chèn biểu tượng bằng Font Awesome 5, áp dụng trực tiếp trong các bài ở trên.

## Chạy thử trên máy

1. Tải hoặc clone repository về máy.
2. Mở thư mục `Tuan3/VeNha/` trong VS Code.
3. Nhấp chuột phải vào `index.html` và chọn **Open with Live Server** (hoặc mở trực tiếp file bằng trình duyệt).
